# GoHighLevel Pipeline Automation — Interactive Demo

Interactive demo: pick a lead source (Website form, Missed call, or Facebook ad lead), run the pipeline, and watch a fictional demo lead move itself through New Lead → Contacted → Qualified → Appointment Booked → Won / Follow-up, with a live automation log, a phone-style simulated message preview, and an outcome card.

This is a scripted simulation for portfolio demonstration only. It places no real calls, sends no real SMS, and books no real appointments. All names and numbers shown are fictional demo data.
